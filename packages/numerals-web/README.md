# Numerals web page

A web page for the Numerals project, built with Next.js v16. Enter a number and see it
converted into all supported numeral systems at once — Eastern Arabic, Mayan, Hieroglyphic,
Roman, Aegean, Thai, Hanifi Rohingya, Kaktovik, and Babylonian — with a light/dark theme
toggle.

web: [numerals.amerharb.com](https://numerals.amerharb.com)
